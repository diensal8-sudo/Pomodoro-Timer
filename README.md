# Pomodoro Timer

A Pomodoro timer built from scratch with plain HTML, CSS and JavaScript. No libraries.

## Features
- Focus (25 min), short break (5 min) and long break (15 min)
- Start / pause / resume and reset
- Animated progress ring (SVG)
- Accurate time using timestamps, not just counting ticks
- Beep sound generated with the Web Audio API
- Session counter saved in localStorage
- Keyboard: Space = start/pause, R = reset

## Run it
Open `index.html` in your browser. Or publish it with GitHub Pages.

## What you learn
- `setInterval` and why `Date.now()` is more accurate
- SVG `stroke-dashoffset` for progress rings
- `localStorage`, the Web Audio API, keyboard events

## In italiano
Un timer Pomodoro fatto da zero con HTML, CSS e JavaScript, senza librerie. Ha tre modalità (focus 25 min, pausa breve 5, pausa lunga 15), anello di avanzamento animato, suono generato dal browser, contatore sessioni salvato in localStorage e scorciatoie da tastiera (Spazio = avvia/pausa, R = reset). Apri `index.html` nel browser per usarlo.
